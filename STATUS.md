# Статус проекта — 25 октября 2026

Актуализировано после подключения истории. Источники: предоставленные владельцем экспорты и результаты тестов в переписке. Проверены JSON, ссылки между workflow и существование целевых узлов соединений; удалённый запуск n8n не выполнялся.

## Архитектура

Цель — многоагентный умный дом с единым оркестратором и специализированными агентами. Экспорт оркестратора не предоставлен.

```text
Чат / вызов из другого workflow
  → Agent energy (Gemini + Simple Memory)
      → HA Read energy context: текущие показатели
      → Energy History → HA_EnergyHistory: история

Отдельно: HA Read context → MCP GetLiveContext
```

## Реализовано

- Текущий контекст: POST /api/template, мощность/энергия/напряжение/ток, группировка помещение → устройство → показания.
- Идентификаторы сущностей и устройств, единицы, исходные статусы, числовые значения и временные поля. Нечисловые значения не превращаются в ноль.
- Разметка месячных и исходных счётчиков кухни и ванной, без суммирования.
- HA_EnergyHistory с ручным и внешним входом. Вход: entity_id, start_time, end_time.
- Общая валидация до HTTP: один запрос, sensor, даты с часовым поясом, начало раньше конца, период не более 7 суток и конец не в будущем. Это текущие ограничения workflow, не ограничения HA.
- Запрос истории с filter_entity_id, end_time и significant_changes_only=0.
- Нормализация вложенного ответа, сортировка, диагностика нечисловых состояний, временных полей, единиц, выхода за период и уменьшений между соседними числовыми записями.
- История подключена к Agent energy через Workflow Tool с параметрами из $fromAI. ID инструмента совпадает с ID экспортированного workflow.
- Normalize history обращается к общему History parameters; тестовая ветка не используется при внешнем вызове.
- Четыре workflow представлены JSON в workflows/. Экспорты сохраняют исходные настройки; изменено только форматирование JSON.

- 212 записей, kWh.
- Первое показание: 29.44; последнее: 31.55.
- Нечисловых значений, некорректных дат, пропущенных единиц и выхода за период не обнаружено.
- Уменьшений между соседними числовыми записями не обнаружено.
- Последняя запись за 671.381 секунды до конца периода. Это само по себе не доказывает пропуск.
- Получен ответ агента с теми же числом записей и крайними показаниями. Трасса выполнения не предоставлена; это подтверждение владельца, а не независимый запуск.
- completeness остаётся not_verified. Разница крайних показаний не объявляется проверенным расходом за сутки.

## Открытые вопросы

- Полнота истории, глубина хранения и поведение на других датчиках/периодах пока не проверены.
- Тест поиска исходного счётчика по названию через текущий контекст, сценарий пустой истории и отрицательные тесты валидации требуют подтверждения.
- В промпте сохраняется требование искать switch, хотя текущий контекст содержит только sensor.
- Промпт запрещает утверждать полноту при not_verified, но ещё не требует явно сообщать это ограничение в каждом соответствующем ответе.
- Проверить публичность чата, sessionId/изоляцию памяти, необходимость availableInMCP и права вызова workflow истории.
- Описания параметров $fromAI в экспорте пустые; смысл параметров задан в описании инструмента.
- Полный каталог измерений, покрытие квартиры и правила агрегации не завершены. Период накопления исходных счётчиков не установлен.
- Хранилище, тарифы, PDF-импорт, Energy — Calculate, прогнозы, предложения и отчёты не реализованы в предоставленных экспортax.

## Публикация и безопасность

Экспорты содержат локальный адрес HA, ссылки на credentials, webhook и служебные ID; публикация исходных настроек согласована владельцем. Значения токенов в просмотренных полях не обнаружены. Это не полный аудит безопасности. Credentials и ссылки на workflow необходимо проверять при переносе в другой экземпляр n8n. Рабочая конфигурация n8n коммитом не изменяется.
