# Smart Home

Многоагентная система умного дома на базе **Home Assistant + n8n + PostgreSQL**.

**Цель:** снижать расходы без ухудшения комфорта и повышать качество проживания. Оркестратор объединяет данные профильных агентов и помогает выбрать полезные изменения; установка, покупки, платежи и управление устройствами требуют отдельного решения владельца.

## Принцип развития

Каждый агент имеет собственный каталог `agents/<agent_id>/` с назначением, интерфейсом, подробной проработкой и планом. Все статусы находятся **только** в `docs/status/`, отдельно от спецификаций. Общие правила и интеграция описываются в `docs/`. Нового агента добавляем без переноса его подробностей в этот README.

**Важно:** GitHub содержит документы и экспорты, а не гарантированно актуальную копию запущенной системы. Что подтверждено и что ещё предстоит проверить, указано в [статусах](docs/status/README.md). Не заменять рабочие workflow экспортами без сверки.
