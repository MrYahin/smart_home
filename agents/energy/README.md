# Энергетический агент

**Цель:** объяснять электрические нагрузки и помогать находить улучшения по потреблению и комфорту на основе **Home Assistant**.

**Работает с:** мощностью (Вт/кВт), энергией (Вт·ч/кВт·ч), напряжением (В), током (А), связью датчиков с устройствами и историческими измерениями.

**Не работает с:** квитанциями ЖКХ, начислениями, платежами, ответами агента УК. Не получает документальные сведения через оркестратор. Источник официальных тарифов ещё должен быть согласован, поэтому стоимость нельзя объявлять рассчитанной.

## Интерфейс

- Вход: пользовательский вопрос и `sessionId`; для истории — точный `entity_id`, границы периода с часовым поясом.
- Инструменты: `HA Read energy context`; `Energy History` → `HA_EnergyHistory`.
- Выход: показатели/история с единицами и привязкой к устройству или помещению, ограничениями качества и времени наблюдения.
