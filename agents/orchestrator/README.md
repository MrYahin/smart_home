# Оркестратор Smart Home

**Цель:** единый диалог с владельцем и обоснованные рекомендации на основе независимых данных профильных агентов, ограничений комфорта и актуальных предпочтений.

**Область ответственности:** понять запрос, определить нужных агентов, передать им только относящуюся к их зоне часть вопроса, согласовать источники и сформировать итог. Не является первичным источником показаний HA или квитанций.

## Входы и выходы

- Вход: вопрос пользователя, `sessionId` и допустимый контекст диалога.
- Источники: ответы агента энергии и агента УК; будущий читаемый профиль PostgreSQL; позднее — ограниченный персональный контекст personal_assistant.
- Выход: ответ с источниками, периодом, единицами, оговорками; при необходимости один точный уточняющий вопрос. Целевое развитие — 1–3 приоритетные рекомендации.

Не выполняет платежи, обращения к поставщикам, покупки, системные настройки или управление устройствами без отдельного решения владельца.
