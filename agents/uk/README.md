# Агент УК — квитанции ЖКХ

**Цель:** помогать владельцу понимать и проверять сохранённые сведения коммунальных квитанций, а не выступать представителем управляющей организации.

**Зона:** все услуги из квитанций (электричество, вода, водоотведение, отопление, подогрев воды, содержание жилья и общее имущество), а также отдельные документы за тепло, содержание жилья и интернет по мере поддержки их форматов.

**Источники:** извлечённые данные PDF, сохранённые в PostgreSQL; не первичные данные Home Assistant. Агент не выполняет платежи, обращения, изменение БД или управление устройствами.

## Интерфейс

- Вход: вопрос; расчётный месяц `YYYY-MM`, год и при необходимости выбранный документ.
- Инструмент: контекст квитанций (`uk_receipt_context`) → PostgreSQL.
- Выход: найденные документы с `document_id`, источником, расчётным месяцем, доступными показаниями/начислениями и ограничениями; возможные статусы `found`, `not_found`, `multiple_documents`.
