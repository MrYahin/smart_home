# Статус: оркестратор

**Основание:** сведения от 2–6 ноября 2026, `workflows/My-workflow.json` из main на 23 ноября 2026. Работающий n8n непосредственно не проверен.

## Подтверждено из экспорта

- `My workflow`: `Chat Trigger` → `AI Agent` с Gemini и `Simple Memory`.
- Подключены инструменты `Call 'Agent energy'` и `uk_agent`, системный промпт разделяет HA и квитанции.
- Память оркестратора использует `orchestrator:uk-energy:v2:<sessionId>`.
- Ветка Webhook Алисы ведёт к фиксированному ответу, не к AI Agent.
- В JSON поле `active: true`; это **не** доказательство работающей опубликованной версии.

## По подтверждению владельца

Новая маршрутизация, агент УК и сохранение обновлённого экспорта от 4 ноября (коммит `67d051b`). Исправлена SQL-ошибка, после чего связка работала.

## Не подтверждено / отсутствует

- Инструмент чтения `owner_profile.preferences` и фактическое использование профиля в рекомендациях.
- Интерфейс к personal_assistant и историческому RAG.
- Тесты изоляции данных при смешанных вопросах и пересказе квитанций из памяти.
- Единый структурированный контракт ответов, 1–3 ежедневных предложения, вечернее обновление дашборда.
- Поддержка загрузки Excel и выдачи файлов в чате.
