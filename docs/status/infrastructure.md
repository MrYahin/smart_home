# Статус: инфраструктура и импорт

**Основание:** подтверждения владельца 2–6 ноября 2026 и JSON-экспорты 23 ноября 2026. Контейнеры, БД, SMB и расписания не проверялись удалённо.

## По подтверждению владельца

- PostgreSQL 18 в Docker на Debian (`smart-home-storage-postgres-1`), БД `smart_home`; связь n8n с БД настроена.
- Схема `energy`: `utility_documents`, `utility_meter_readings`, `utility_charges`; результат JS-парсера хранится в JSON payload документа.
- Схема `owner_profile`, права `USAGE/CREATE` роли `n8n_app`, таблица `preferences` с полями `id`, `preference_key`, `preference_value`, `description`, `created_at`. Тестовый workflow INSERT/SELECT пропущен; начальные значения не подтверждены.
- SMB-путь: `/home/yaha/utility-import/incoming` на хосте → `/files/utility-import` в n8n; ранее указывался UID/GID `1000:1000`.
- При последовательном импорте PDF извлекается текст, JS-парсер сохраняет результаты, затем удаляется конкретный файл. Ручные исправления проблем некоторых квитанций подтверждались владельцем.

## Что обнаружено в экспортном снимке

- `ZhKKh-Import-PDF.json` содержит ручной триггер, чтение PDF, парсер, PostgreSQL и `Execute Command` для удаления; `active: false`.
- `Postgres.json` — ручной SELECT `energy.document_meter_readings` для одного документа, **не миграция** и не доказательство наличия таблицы.
- Экспорт парсера устарел: в рабочей версии вручную исправлялись колонка пени, склейка кода расчёта со ставкой и отдельный заголовок подогрева воды.

## Не проверено / ограничения

- Автоматический импорт по расписанию и полнота всех форматов.
- Отсутствие дублей: дедупликация не добавлялась; после успешного INSERT и сбоя удаления PDF возможен повторный импорт.
- Арифметические проверки, подтверждение перед сохранением, исходный архив PDF и отдельный журнал ошибок не входят в согласованный упрощённый процесс.
- Расписание/официальность ставок, полнота долгов и оплат, арифметическое совпадение с PDF.
- Compose-файлы, SQL-миграции, резервные копии с восстановлением, конфигурация дашборда, аудит секретов — в репозитории отсутствуют/не подтверждены.
- Автоматическое получение квитанций из Комфорт-сити, МОЭК, mos.ru или Дом.ру отложено.

**Следующий тест:** проверить права и чтение предпочтений; на новых образцах проверить форматы, неуспешный импорт и сохранение исходного PDF. Обновить export после ручной сверки.
