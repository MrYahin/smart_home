# Статус проекта Smart Home

**Срез:** 6 ноября 2026; повторно сверен с репозиторием 23 ноября 2026 без доступа к работающей системе.

## Подтверждения из истории проекта

- По словам владельца от 2–6 ноября, общий чат n8n с оркестратором и двумя профильными агентами опубликован, связка заработала после исправления SQL.
- Показатели HA и история электрических датчиков оформлены в отдельных workflow.
- PostgreSQL подключён к n8n; документы ЖКХ извлекаются из PDF и записываются в схему `energy`.
- Подготовлена схема `owner_profile`, таблица `preferences` и права роли n8n (по подтверждению владельца).

Это **сообщённая готовность**, не независимый end-to-end тест в текущем сеансе.

## Проблемы воспроизводимости

- Экспорт оркестратора новее экспортов энергетического агента и квитанционного инструмента.
- Нет отдельного экспорта агента УК и актуального общего контекста квитанций.
- Не зафиксированы Compose, схема миграций PostgreSQL и YAML/настройки HA-дашборда.
- Существующий `workflows/ZhKKh-Import-PDF.json` не включает часть позднее подтверждённых исправлений парсера.
- Поэтому **восстановление системы только из репозитория не гарантировано**.

## Ближайшие проверки

1. Сверить версии экспортов с рабочими n8n workflow и сохранить снимки **после проверки**, не перезаписывая ими рабочую конфигурацию.
2. Согласовать стартовые предпочтения владельца и подключить чтение в оркестратор.
3. Проверить новые форматы квитанций по отдельным тестовым примерам и безопасность неизвестного формата.
4. Подтвердить резервное копирование/восстановление и отсутствие секретов в опубликованных файлах.
