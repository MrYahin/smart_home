# Статус проекта Smart Home

**Подтверждения действующей системы:** по переписке и документации от 2–6 ноября 2026; структура репозитория проверялась 23 ноября 2026. Прямой проверки запущенных n8n, HA, PostgreSQL или SMB нет.

## Известная основа

- По подтверждению владельца, общий чат n8n и два профильных агента (энергетика, УК) работали после исправления SQL.
- Показатели HA и электрическая история представлены экспортами отдельных workflow.
- PostgreSQL использовался для квитанций ЖКХ; схема `owner_profile.preferences` подготовлена по сообщениям владельца.
- В репозитории нет полного воспроизводимого набора актуальных экспортов: оркестратор новее агентных версий, отсутствуют отдельный агент УК, текущая версия парсера, Compose и миграции.

## Концепции, добавленные 23 ноября 2026

- Семь новых агентов: HVAC, растения, автомобиль, лекарства, сервис, безопасность и автоматизированные покупки — **все только запланированы**.
- Оркестратор получает целевую роль стратегического планировщика развития дома: рекомендации по закупкам, модернизации и будущим мероприятиям.
- Предлагаются скоринг, учёт решений, измерение эффекта и периодические обзоры. **Не реализованы**: workflow, реестр инициатив, расписание, реальные автоматические действия.

## Ближайшие проверки

1. Сверить запущенные workflow с сохранёнными экспортами и не перезаписывать рабочие старой версией.
2. Согласовать начальные предпочтения владельца и проверить их чтение оркестратором.
3. Подготовить инвентаризацию устройств, условий, источников данных и приоритетов внедрения новых агентов.
4. Проверить новые форматы квитанций, безопасность импорта и качество истории HA.
5. Перед изменениями БД/автоматизаций отдельно согласовать схемы, разрешения, журнал и откат.
6. Разработать проверяемый сценарий 1–3 рекомендаций на основании фактов, с учётом отклонённых инициатив.
