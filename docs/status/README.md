# Статусы Smart Home

**Единое место для сведений о готовности, фактических проверках, проблемах и устаревших экспортах.** В `agents/` и общем плане публикуем требования и проработку, а не статус выполнения.

**Дата составления этой сводки:** 23 ноября 2026. **Основание:** `main` репозитория в коммите [`6f5c96c`](https://github.com/MrYahin/smart_home/commit/6f5c96c65e63f8594f8904147eef327a9092b4ca), документы с последними подтверждениями владельца **от 2–6 ноября 2026** и прочитанные JSON-экспорты. **Прямой проверки HA, n8n, PostgreSQL или SMB 23 ноября не было.** Запись «подтверждено владельцем» не означает проверку на сервере.

| Подсистема | Статус и риски |
| --- | --- |
| [Проект целиком](project.md) | Общая картина, соответствие репозитория рабочей системе, следующий этап |
| [Оркестратор](orchestrator.md) | Сохранённый экспорт, маршрутизация, чтение предпочтений |
| [Энергетический агент](energy.md) | История и контекст HA, устаревший экспорт агента |
| [Агент УК](uk.md) | Квитанционный контекст, отсутствие экспорта агента, качество импорта |
| [Инфраструктура](infrastructure.md) | PostgreSQL, SMB, PDF, экспортные расхождения, резервирование |

При изменении работы агента обновить **его один** статус-файл, не расписывая историю в корневом README. Формат записи: дата → источник (владелец / экспорт / исполнение) → подтверждённый результат → не проверено → следующий тест. Временные обещания и `active: true` не считать доказательством работоспособности.
