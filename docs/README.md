# Документация Smart Home

В этом каталоге хранятся межагентная архитектура, технические соглашения, инфраструктура, принятые решения и **все сведения о текущем состоянии**. **Каталог агентов и общая дорожная карта ведутся в [корневом README](../README.md)**, а не здесь.

- [Архитектура](architecture.md) — границы компонентов, маршрутизация, источники данных и общие интерфейсы.
- [Статусы](status/README.md) — результаты проверки системы, актуальность экспортов и открытые риски.
- [Решения: развитие умного дома](decisions/home-improvement.md) — цикл улучшений, оценка инициатив, будущий реестр и отчёты.
- [Решения: персонализация](decisions/personalization.md) — PostgreSQL → будущий personal_assistant / RAG.
- [Решения: интерфейс и файлы](decisions/interface-files.md) — чат n8n, перспектива Open WebUI, загрузка и выдача файлов.
- [Инфраструктура: PostgreSQL](infrastructure/postgresql.md) — схема и правила изменения данных.
- [Инфраструктура: импорт PDF](infrastructure/pdf-import.md) — поток документа и защита исходных файлов.
- [Инфраструктура: безопасность](infrastructure/security.md) — технические границы и секреты.

Подробное описание каждого агента находится в `agents/<id>/`. Краткая цель и ссылки на всех агентов поддерживаются в [общем каталоге](../README.md#каталог-агентов).

## Где размещать новые сведения

- **Краткое назначение и регистрация нового агента** → таблица в корневом `README.md`.
- **Цель, ответственность, инструменты и входы/выходы агента** → `agents/<id>/README.md`.
- **Алгоритмы, примеры и подробная техническая проработка** → `agents/<id>/DESIGN.md`.
- **Будущие задачи агента и критерии готовности** → `agents/<id>/ROADMAP.md`.
- **Реализовано, протестировано, не проверено и устаревшие экспорты** → `docs/status/<id>.md`.
- **Общее изменение архитектуры** → `docs/architecture.md` или `docs/decisions/`.
- **Общепроектные этапы и приоритеты** → раздел [«Общая дорожная карта»](../README.md#общая-дорожная-карта).

Статусы привязывать к **дате и источнику сведений**: экспорт / подтверждение владельца / проверка на сервере. Отсутствие проверки не заменять предположением.
