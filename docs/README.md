# Документация Smart Home

В этом каталоге — межагентная архитектура, технические соглашения, инфраструктура, принятые решения и **все сведения о текущем состоянии**. **Каталог всех агентов и общая дорожная карта ведутся только в [корневом README](../README.md)**.

- [Архитектура](architecture.md) — границы компонентов, маршрутизация и источники.
- [Статусы](status/README.md) — результаты проверки, актуальность экспортов и открытые риски.
- [Проактивное развитие дома](decisions/improvement-planning.md) — цели и правила анализа улучшений, приоритеты и жизненный цикл инициатив.
- [Решения: персонализация](decisions/personalization.md) — PostgreSQL → будущий personal_assistant / RAG.
- [Решения: интерфейс и файлы](decisions/interface-files.md) — чат n8n, перспектива Open WebUI, загрузка и выдача файлов.
- [Инфраструктура: PostgreSQL](infrastructure/postgresql.md) — схема и правила изменения данных.
- [Инфраструктура: импорт PDF](infrastructure/pdf-import.md) — поток документа и защита исходников.
- [Инфраструктура: безопасность](infrastructure/security.md) — технические границы и секреты.

## Куда писать новую информацию

| Информация | Единственное основное место |
| --- | --- |
| Каталог агентов, их краткие цели и общая дорожная карта | [README в корне](../README.md) |
| Цель, задачи, интерфейс конкретного агента | `agents/<id>/README.md` |
| Подробный дизайн, контракты и сценарии | `agents/<id>/DESIGN.md` |
| Индивидуальная последовательность разработки | `agents/<id>/ROADMAP.md` |
| Подтверждённое состояние, проверки, открытые риски | `docs/status/<id>.md` |
| Общие архитектурные решения | `docs/architecture.md` и `docs/decisions/` |

Статусам всегда указывать **дату и тип источника** (владелец, экспорт, непосредственное исполнение). Запланированное не выдавать за внедрённое.
