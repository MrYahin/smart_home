# Главная вкладка Home Assistant (`main`)

**Источник:** присланный владельцем `main.txt`, 27 ноября 2026 года.
**Состав переданного материала:** **одна карточка** `picture-elements`, не полный YAML дашборда и не экспорт настроек всей вкладки.
**Конфигурация:** [cards.yaml](cards.yaml).

## Существующая карточка

- Фон — `/local/home_background.png`; виджет времени через Markdown.
- Земной шар `custom:earth-globe-card`, настройка облаков `input_boolean.earth_clouds`.
- Изображение Луны, загружаемое с отдельного HTTP-источника.
- Состояние погоды и температура/влажность/ветер из `weather.forecast_home`, карточка прогноза на дни.
- `custom:horizon-card` с информацией о восходе/закате и азимуте.
- Оформление через `custom:hui-element`, `card_mod`, прозрачные элементы, координаты в процентах.

**При публикации:** прямой IP-адрес HTTP-источника изображения Луны заменён на `REPLACE_WITH_MOON_IMAGE_HOST`; в рабочей конфигурации HA он остаётся прежним. Для использования файла из GitHub нужно вернуть согласованный адрес источника. Другие настройки и идентификаторы сущностей в присланной карточке сохранены. Не хранить адрес исходного сервиса в публичном GitHub.

## Рекомендации оркестратора (план)

На **главной вкладке**, а не внутри карточек профильных подсистем, показывать 1–3 **общедомовые** рекомендации оркестратора: новые покупки, модернизация, обслуживание и запланированные активности.

**Предлагаемое размещение:** самостоятельная карточка/секция рядом с существующим `picture-elements` или ниже него, **не накладывая её на глобус, часы, погоду и горизонт**. Конкретное размещение зависит от полного layout главного дашборда, который ещё не получен. Поэтому `cards.yaml` содержит только оригинальную присланную карточку; рекомендательная карточка не добавлена как якобы уже работающая.

**Хранилище:** отдельный список `Local To-do` для главной вкладки, две стадии `needs_action` / `completed`; операции «В работу», «Не сейчас», «Подробнее», «Выполнено» — будущие автоматизации HA/n8n. Точное `todo.*` имя ещё не определено.
