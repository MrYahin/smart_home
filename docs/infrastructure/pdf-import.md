# Импорт квитанций PDF через SMB и n8n

## Согласованный процесс

Владелец **сам получает** квитанции и помещает PDF в существующую папку. Для сервера и контейнера исторически заданы пути:

- хост Debian: `/home/yaha/utility-import/incoming`;
- внутри n8n: `/files/utility-import`.

Целевой поток:

```text
SMB → папка → чтение PDF n8n → извлечение текста
    → распознавание формата → соответствующий JS-парсер
    → PostgreSQL (документ, показания, начисления)
    → удаление только этого PDF после подтверждённой записи
```

В workflow есть шаги `Read/Write Files from Disk`, `Extract from File`, JS-парсер, PostgreSQL, `Loop Over Items`, проверка имени/пути и `Execute Command` на удаление. На новых форматах требуется отдельно проверить корректность распознавания и обработки ошибок.

## Границы безопасности и трактовки

- Имя — допустимый `.pdf` без разделителей пути и управляющих символов; путь должен совпадать с разрешённой входной папкой. Удалять **только** конкретный файл после подтверждения записи документа, не всю папку.
- Неизвестный формат и ошибка обработки — неуспех; PDF сохраняется для ручного анализа.
- Гостевой SMB допускается лишь в доверенной локальной сети; папка доступна клиентам для изменения/удаления. Не публиковать SMB в интернет.
- `Execute Command` расширяет возможности workflow: ограничения нод n8n не являются песочницей shell.
- Не публиковать исходники квитанций и персональные строки из них.
- Успешное сохранение записи не доказывает корректность сумм, полноту разбора или обоснованность начислений.

## Принятый объём

План расширения: электричество, тепло, содержание жилья, интернет, включая отдельные квитанции. Для каждого **конкретного** формата проверять признаки, поставщика, расчётный месяц и все требуемые поля.

Сохранить упрощённый импорт: **не** вводить автоматически дедупликацию, промежуточное подтверждение, арифметические сверки, архив исходных PDF и дополнительный журнал ошибок. Такие изменения — только после отдельного согласования. Автоматическая загрузка из Комфорт-сити, МОЭК, mos.ru или Дом.ру отложена. Работа по расписанию требует отдельной проверки.
